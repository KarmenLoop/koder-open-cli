# Current development scope

Version 0.2.0-dev.4 is a development candidate. It keeps the original 20 industry seeds, 18 channel catalog entries, versioned settings, rollback and local Studio. It adds an interactive TUI, scoped text-skill intake, activation controls, output checks, explicit preference suggestions, a learning cycle and three text API transports.

Learning uses only approved role topics, selected active sources and explicitly submitted records. It supports preparation, local review practice, remediation and bounded simulations with owner review. It does not monitor applications, train model weights, run an unattended scheduler or execute real external tasks. New learning context cannot expand permissions.

Native macOS and Windows evidence, real provider-adapter tests and customer authorization acceptance remain separate. See VALIDATION.md for the tested paths and limits. Connected business channels, external tools and cross-device execution remain unavailable.

The publisher is KARMENLOOP Team, Shanghai, China; info@karmenloop.com; https://karmenloop.com. The dedicated private receipt repository exists. The product OAuth App, HTTPS issuer and deployment signing configuration are not provisioned. Personal, noncommercial licensing restricts product-code changes and commercial use; user-authored roles and skills remain editable. Third-party license grants remain separate.
